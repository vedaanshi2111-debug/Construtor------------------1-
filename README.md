Features

Add multiple characters at once 

Store details like:

Name

Age

Race

Height

Attack Power


View details of a specific character

How It Works

1. When the program starts, it asks for the number of characters you want to enter.


2. For each character, the program collects:

Name

Age

Race

Height

Attack Power



3. After data entry, you can choose:

Which character number you want to view

Which specific detail you want to see (like only Name, Age, or Race)

4. Based on your selection, the program displays the requested information on the screen.

5. The design uses arrays and a constructor to organize input and output efficiently.
